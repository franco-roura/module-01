# Select

A single choice from a short list, on Radix Select.

Compose `Select`, `SelectTrigger` with a `SelectValue`, and `SelectContent` with `SelectItem`s. `SelectGroup`, `SelectLabel` and `SelectSeparator` structure longer lists.

- For up to about eight options. A longer or searchable list is a Combobox.
- The trigger is a sunken well like Input; the list is a `shell` popover with `shadow-float`.
- Picking an option moves focus to the next field (see Combobox, Form flow).
