# Command

A searchable list on cmdk: the engine inside Combobox, and a command palette on its own.

Compose `Command` with `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup` and `CommandItem`. `CommandDialog` puts it in a Dialog.

- Reach for Combobox or MultiCombobox for form fields. Use Command directly for a palette or a custom picker.
- Group headings are `hud-sm`; the empty state is one plain sentence.
