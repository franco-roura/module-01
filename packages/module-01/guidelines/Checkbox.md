# Checkbox

A small sunken square that fills `signal` when checked.

Takes Radix Checkbox props: `checked`, `defaultChecked`, `onCheckedChange`, `disabled`. Pair it with a Label through `id` and `htmlFor`.

- Unchecked it's a `shadow-press` well; checked it carries an `ink` check on `signal`.
- Use it for options that apply on submit. A setting that applies at once is a Toggle.
