# HudLabel

Mono overline with a signal code chip, a label and a seam rule that runs to an end marker.

Provide `children` (label) and optional `code` (e.g. `S-02`), `end` (right-side microprint like `02/04`), `rule={false}` to drop the line.

- The code chip is `signal` with `ink` text, `radius-xs`. Labels in `ink-soft`.
- Sits `space-3` above every section heading and at the top of large panels.
